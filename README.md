# Pawan Kumar Portfolio

A responsive Next.js + Tailwind CSS portfolio and monthly website-care landing page.

## Run locally

1. Install Node.js 20 or newer.
2. Extract this folder and open a terminal inside it.
3. Run:

```bash
npm install
npm run dev
```

4. Open http://localhost:3000

## Important: customize before publishing

Open `components/portfolio.tsx` and replace:

- `WHATSAPP_NUMBER` with your WhatsApp number including country code, without `+`.
- `EMAIL` with your real business email.
- `LINKEDIN_URL` with your LinkedIn profile URL.

Also review all claims, pricing, project descriptions and experience details. Add only genuine screenshots, links, testimonials and case studies. The project cards are currently illustrative summaries, not live portfolio links.

## Build

```bash
npm run build
npm start
```

## Deploy

Push the project to GitHub and import it into Vercel, or deploy it to another host that supports Next.js. Configure the same environment and build settings there.
